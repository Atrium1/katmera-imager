# Katmera brand tokens (Imager)

Derived from the official KATMERA wordmark assets.

| Token | Hex | Use |
|-------|-----|-----|
| `katmeraOrange` | `#F86000` | Primary accent, buttons, sidebar active, progress |
| `katmeraCharcoal` | `#202830` | Wordmark / dark text companion |
| Background | `#FFFFFF` | App chrome (light UI) |

## Logo assets

| File | Use |
|------|-----|
| `katmera-logo-color.png` | Full color wordmark (icon + KATMERA) on light backgrounds |
| `katmera-logo-mono.png` | White wordmark on transparent (dark surfaces) |
| `katmera-mark.png` | Icon-only mark (gear/circuit K) for app icon & list rows |

Wired into the app as:

- `src/icons/logo_sxs_imager.png` — color wordmark (welcome / sidebar)
- `src/icons/logo_sxs_imager_mono.png` — mono wordmark
- `src/icons/logo_stacked_imager.png` — compact color wordmark
- `src/icons/katmera-mark.png` — 40×40 list / catalog icon
- `src/icons/rpi-imager.ico` / `AppIcon-compiled.icns` — window & bundle icon

App display name: Katmera Imager  
Bundle / AppStream ID: com.katmera.imager  
Binary: katmera-imager

Attribution to Raspberry Pi Imager must remain in About/NOTICE.
